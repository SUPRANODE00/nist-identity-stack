# Firecrawl Agent Skill

This skill enables the agent to search, scrape, and browse the web using Firecrawl.

## Capabilities
- Web search
- Web scraping
- Structured extraction
- Real-time browsing

## API Configuration
Use the FIRECRAWL_API_KEY secret to authenticate.

## Usage
The agent can call Firecrawl tools to retrieve fast, token-efficient web data.
